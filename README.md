## 📱 Android APK — Two Ways

### Option A — Build automatically with GitHub Actions (zero local setup) ⭐

This repo includes `.github/workflows/android-apk.yml` which builds an APK on every push to `main`.

**Steps:**
1. Push the repo to GitHub
2. Go to your repo → **Actions** tab → wait for the workflow to finish (~5–10 minutes the first time)
3. Click the completed workflow run → scroll down → download the **`madskillz-android-apk`** artifact
4. Unzip — you'll have `madskillz-ai-readiness-debug.apk` ready to install on any Android device

**To create a versioned release** (with a permanent download link):
```bash
git tag v1.0.0
git push origin v1.0.0
```
This creates a GitHub Release with the APK attached publicly. Anyone can download it directly.

### Option B — Build locally (requires Android Studio)

**Prerequisites:**
- [Node.js 18+](https://nodejs.org/)
- [Android Studio](https://developer.android.com/studio) with Android SDK installed
- Java JDK 21

**Steps:**
```bash
# 1. Build the web app and add Android platform
npm install
npm run build
npx cap add android        # only the first time

# 2. Open in Android Studio
npx cap open android
# Then click ▶ Run, or Build > Build Bundle(s)/APK > Build APK

# OR build APK from terminal directly:
npm run android:build
# APK will be at: android/app/build/outputs/apk/debug/app-debug.apk
```

### Installing the APK on Android

1. Transfer the APK to your phone (email, Google Drive, USB)
2. Tap the file — Android will warn about "unknown sources"
3. Go to **Settings → Security → Allow install from unknown sources** for your file manager
4. Tap **Install**

> The debug APK is unsigned — perfect for testing and sharing internally. For Google Play Store, you need a signed release APK (see the "Production Release" section below).

## 📦 Production Release (Signed APK for Play Store)

To distribute on the Play Store you need a signed release APK:

```bash
# 1. Generate a keystore (do this ONCE, save the file securely)
keytool -genkey -v -keystore madskillz.keystore -alias madskillz -keyalg RSA -keysize 2048 -validity 10000

# 2. Add signing config to android/app/build.gradle (after running cap add android)
#    See: https://capacitorjs.com/docs/android/deploying-to-google-play

# 3. Build release APK
npm run android:release
```

**Never commit your keystore or passwords to GitHub.** Add them to `.gitignore` (already done) and store them safely.

## 🧠 How the Exposure Engine Works

The engine scores 6 dimensions (0–100) per career:

1. **Repetitive tasks** — How predictable / rule-based the work is
2. **Creativity required** — Original thinking, design, problem-solving
3. **Human interaction** — Empathy, persuasion, emotional intelligence
4. **Technical complexity** — Specialized knowledge
5. **Physical presence** — Hands-on / on-site requirements
6. **AI adoption speed** — How fast the industry is integrating AI

Repetitive + technical + AI-speed raise exposure; creativity + human + physical reduce it. The result maps to 5 risk tiers: Very Low → Critical.

For non-careers ("father", "wife", "human"), the classifier routes to a **0% replaceability** screen with reassuring messaging.

## 🎨 Customization

### Add a new career
Edit `CAREERS` array in `src/App.jsx`:
```js
{ id: "your-id", name: "Your Career", icon: "🎯",
  repetitive: 50, creativity: 70, human: 60, technical: 65, physical: 30, aiSpeed: 70,
  skills: [...], futureRoles: [...] }
```

### Add a new language
Add a key to `TRANSLATIONS` and a matching entry to `LANGS` in `src/App.jsx`.

### Update Team21 programs / contact
Search `src/App.jsx` for:
- `TEAM21_WA` — your WhatsApp number
- `team21online@gmail.com` — your email
- `Team21 AI Unlocked` / `Team21 AI Builder` — program names

### Change app icon (Android)
After running `npx cap add android`, replace icons in `android/app/src/main/res/mipmap-*/`. Use [Android Asset Studio](https://romannurik.github.io/AndroidAssetStudio/) to generate proper sizes from a single image.
